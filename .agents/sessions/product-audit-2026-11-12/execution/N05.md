# N05 — Web egress safety (receipt)

**Status:** implemented.

Findings: web-media-evals-01 (IPv4-mapped/compatible/NAT64 bypass, confirmed `200 INTERNAL-SECRET`), web-media-evals-02 (check-then-connect rebinding window). The MCP blocklist had the same gap (`isBlockedMcpAddress('::ffff:7f00:1') === false`).

## Changed files
- `common/src/util/ip-address-policy.ts` (new): the single shared classifier. `classifyIpAddress`, `classifyHost`, `isBlockedHost`, `isBlockedIpAddress`, `parseIpv4Literal`, `parseIpv6Literal`, `canonicalizeIpv4`. It parses to numbers, not string shapes. IPv4 is accepted in dotted, decimal-integer, octal, hex and inet_aton shorthand forms. Malformed numeric hosts are refused. IPv6 is fully expanded (brackets and zone ids allowed). The embedded IPv4 address is unmapped from `::ffff:0:0/96` (dotted and hex), `::/96` (IPv4-compatible), `::ffff:0:0:0/96` (SIIT), `64:ff9b::/96` (NAT64) and `2002::/16` (6to4), then the v4 rules apply. Blocked categories: unspecified, loopback, private (RFC 1918, fec0::/10, 64:ff9b:1::/48), link-local, CGNAT 100.64/10, unique-local fc00::/7, multicast, metadata (169.254.169.254, 169.254.170.2, 100.100.100.200, fd00:ec2::254), documentation, and reserved (0/8, 192.0.0/24, 192.88.99/24, 198.18/15, 240/4, 100::/64, Teredo 2001::/32). Blocked names: localhost, metadata, metadata.aws/google.internal, instance-data(.ec2.internal), and `*.localhost`, `*.local`, `*.internal`.
- `common/src/util/pinned-fetch.ts` (new): pinned-address transports generalized from the MCP NEW-7 design. `buildPinnedRequest` rewrites the URL to the IP and keeps the original `Host` and `tls.serverName`, with `redirect: 'manual'`. `nodePinnedRequest` uses `node:http(s)` with a `lookup` hook that always returns the pinned address, so SNI and certificate checks stay on the real name. It handles gzip, deflate and br. `fetchPinnedAddress` picks Bun fetch for http and Bun https, and the node transport for https where `tls.serverName` is unsupported (Node). `runtimeSupportsTlsServerName` moved here.
- `common/src/mcp/client.ts`: `isBlockedMcpAddress` now delegates to `isBlockedHost`. The private copies (`isNumericIpv4Candidate`, `parseIpv4NumericComponent`, `canonicalizeIpv4Shorthand`, `isBlockedIpv4`, `isBlockedIpv6`) and the unused `isIP` import were removed. This was a targeted edit inside a file with large uncommitted B19–B21 changes. Nothing else in the file was touched.
- `common/src/mcp/dns-pinning.ts`: `createPinnedMcpFetch` now uses the shared `buildPinnedRequest` for the URL rewrite. `runtimeSupportsTlsServerName` is re-exported from `pinned-fetch.ts`. Behavior is unchanged except one thing: for an IPv6-literal MCP URL, the Host header is now bracketed (`[::1]:port`), which is RFC-correct.
- `packages/agent-runtime/src/tools/handlers/tool/web-search-utils.ts`: the local blocklist was removed and `isBlockedWebAddress` delegates to `classifyIpAddress`. New `resolveSafePublicWebTarget` validates the URL, classifies the host, resolves once (injectable `resolveHost`) and refuses the host if any resolved address is blocked. `fetchPublicWebUrl` dials the validated address through `fetchPinnedAddress` on every hop and re-resolves and re-checks each redirect `Location`. New `WebEgressOptions` seam (`resolveHost`, `fetchImpl`, `supportsTlsServerName`). `assertSafePublicWebUrl` keeps its signature (with optional options).
- `packages/agent-runtime/src/tools/handlers/tool/web-search.ts`: optional `webEgress` test seam threaded into both the URL and search paths (also used by N04).
- `common/knowledge.md`: one knowledge line for the new modules (needed by the memory-drift guard).
