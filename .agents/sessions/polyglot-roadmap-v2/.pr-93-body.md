## Polyglot re-audit remediation — protocol reliability, compaction quality, durability groundwork

Branch: `feat/polyglot-reaudit-roadmap`. Roadmap + specs live under `.agents/sessions/polyglot-roadmap-v2/` (SPEC.md D1–D28, PLAN.md task ledger).

### Landed this series (per-commit changelog)

**Protocol reliability (D19–D24 / PR-T1..T6)**
- **PR-T1 (D19)** typed subagent handoff envelope — additive `outcome` enum on `agentReceiptSchema`; runtime derives outcome (crashed > missing_output > schema_invalid > truncated > ok) and downgrades a falsely-`completed` receipt to `partial`. Closes the D24 status fail-open.
- **PR-T2 (D20)** out-of-band output store — `last_message` fragment merge + content-addressed scratch persistence of full subagent output with a bounded parent pointer.
- **PR-T3 (D21)** tool-argument normalization at dispatch — schema-driven fail-closed unserialize of stringified array/object fields, counted via `toolArgNormalizationStats`. Slice 2 (schema flattening) **closed as superseded** with recorded rationale + walker-recursion regression test.
- **PR-T4 (D22)** plain-text edit payloads behind `OPENBUFF_EDIT_BLOCKS` (default off, byte-identical flag-off). Deterministic eval 10/10 (block/json 0.795–0.984). Live completion-rate A/B remains a manual gated step (no provider keys in CI).
- **PR-T5 (D23)** content-hash attestation + gate arming — reviewer receipts bind to per-file content hashes; docs-only edits don't re-arm review; `scripts/memory-drift-guard.ts` accepts a recorded LOOKS_GOOD review receipt instead of a timestamp-only knowledge.md touch.
- **PR-T6 (D24)** fail-loud structured outputs + the `context-pruner` `'answers' in value` crash fix (guards non-object tool-part values).

**Compaction quality & archive recall (D25–D28 / CQ-T1..T4)**
- **CQ-T1 (D25)** hosted-model retention floor — `enforceKnowledgeMemoryBudgets` excludes open blockers + reviewer receipts from ceiling eviction, with a superseded-review collapse keeping the hard ceiling enforceable (performance-specialist hardened). Retention eval is now the blocking floor (9→11 scenarios).
- **CQ-T2 (D26)** evicted tool-result segments become retrievable archive records (`tool_result_eviction` snapshots with step provenance, bounded by the persisted 8×200×4k caps); round-trip recall test.
- **CQ-T3 (D27)** indexed `recall_context` — in-memory bun:sqlite FTS5 index per call with fail-open to the byte-identical scanner; `indexState`/`indexError` make empty-from-healthy distinguishable from failed-index.
- **CQ-T4 (D25)** multi-pass drift sweep — S10/S11 assert the retention floor survives repeated + oscillating compaction cycles.

**Durability groundwork (P2)**
- **P2-T2 archive-persistence slice** — verified + regression-pinned that `AgentState.compactionArchive` survives across sessions through the checkpoint, chat-state, and SDK restore seams (no persistence code needed fixing).
- **P2-T1 slice 1** — injectable `IdGen` on `AgentRuntimeDeps` (optional, additive) routing the run-path identity mint sites (`agentStepId`, `toolCallId`) through `idGen.uuid()`; three spy tests converted to inject a mock idGen. The determinism prerequisite for P2-T2 replay.
- **P2-T2 design doc** — `.agents/sessions/polyglot-roadmap-v2/P2-T2-DESIGN.md`: append-only bun:sqlite run-journal schema, four write points, replay-by-re-driving-the-generator resume model with tool-result idempotency short-circuit, and the kill-9 resume test.

**Hardening**
- CLI payload sanitizer credential-key redaction moved from substring to a word-boundary rule: metadata keys (`refreshTokenCount`, `maxTokens`, `tokenizer`, …) are kept while every real credential key still redacts.
