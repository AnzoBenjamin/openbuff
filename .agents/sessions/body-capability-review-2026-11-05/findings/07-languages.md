Eleven findings have exact current source anchors and behavioral acceptance probes in the JSON. Six are high severity; five are medium. The following observations are reproduced or directly traced, with inference limits stated where real servers/installations were not exercised.

07-F1 — HIGH — The binary builder creates `tree-sitter-queries/` (`cli/scripts/build-binary.ts:658`), but both release tar lists omit it (`.github/workflows/cli-release-build.yml:460,644`). SDK packaging copies WASM without queries (`sdk/scripts/build.ts:147,508`); its old `.scm` loader cannot embed bare filenames. Runtime lookup also depends on dynamically resolving the internal code-map package (`packages/code-map/src/utils.ts:25`). Missing queries remove scoring and call/import captures, although AST outlines may survive. Isolated package/archive probes must require actual semantic output, preserve explicit directory overrides, and avoid build-checkout visibility.

07-F2 — HIGH — `getLanguageFamily(".py")` and `.rs`, `.go`, `.java`, `.rb` return an empty string (`common/src/util/language-profiles.ts:163`). Code-map supplies bare extensions for definitions but paths for callers (`parse.ts:891,905`), dropping Python caller edges. Indexer supplies bare extensions on both sides (`metadata-indexer.ts:1408`), collapsing unrelated languages. The real fixture emitted a Python call edge to a Rust definition with the same name. Existing TS/Python exclusion tests miss this case. Make path/extension inputs equivalent across every language and pin positive and negative edges.

07-F3 — HIGH — SCIP caps the occurrence’s symbol itself (`packages/indexer/src/scip-ingest.ts:367`), then uses that shortened string to join references to definitions (`:265,276`). Two distinct 231-character descriptors in the probe collapsed; a reference to A pointed to `b.ts` with `confidence: precise`. The existing cap test checks one identity, so it rewards bounded labels without protecting semantic identity. Keep the full bounded descriptor or digest for matching, truncate presentation separately, and test collisions plus multiple-definition ambiguity.

07-F4 — HIGH — Query opening uses connection version 1 (`lsp-multiplexer.ts:1040`), while post-edit sync starts a separate counter at 1 (`language-intelligence.ts:979`). The strict peer rejected that first `didChange` and returned old hover text after disk changed. LRU eviction also resets counters without reopening (`:593`), and capped or oversized already-open files remain stale. The existing version test observes a fake multiplexer, missing this integration. Share document/version authority and invalidate skipped dirty documents so later queries reread committed bytes.

07-F5 — HIGH — Framing failures call `handleGone`, which clears the child without killing it (`sdk/src/services/lsp-multiplexer.ts:572`). The delayed restart does not check disposal before starting its replacement (`:961`); disposal joins neither restart nor replacement (`:1443`). The probe produced two fake children, zero kill calls, and a reported pool size of zero. Preserve handles through termination, cancel and join restarts, and require ownership checks before publication. Pool counts alone cannot serve as process-lifetime evidence.

07-F6 — MEDIUM — `defaultRootResolver` stops only when its selected root differs from the starting parent (`sdk/src/services/lsp-multiplexer.ts:668`). A matching `pkg/tsconfig.json` beside the queried file leaves that comparison false; the later ancestor `package.json` overwrites it. The fixture reproduced the wrong root. Track successful discovery explicitly and cover parent-directory matches, preserving the documented priority policy and cache behavior.

07-F7 — HIGH — Capture discards timeout, exit-code and error fields (`diagnostic-delta.ts:232`), then empty deltas become accepted (`:463`) and hooks label them `diagnostic_delta_passed` (`file-change-hooks.ts:1691`). The DI timeout/127 probe reproduced acceptance. Known Java files select no commands; TS and Python consume the four-command cap before Rust/Go. Nested toolchains receive repository cwd. Return command and coverage outcomes, preserve explicit optional checks, and expose unavailable, incomplete or failed observation instead of asserting successful diagnostic evidence.

07-F8 — MEDIUM — The multiplexer sends profile IDs directly in `didOpen` (`lsp-multiplexer.ts:1040,1437`). The probe sent `typescript` for JavaScript, JSX and TSX, and `cpp` for C. Toolchain grouping is useful for prompts but loses protocol document distinctions. Map source suffixes to canonical document IDs and test real JSX/JavaScript server behavior; the downstream impact remains server-dependent.

07-F9 — MEDIUM — All incoming messages carrying `method` are ignored (`lsp-multiplexer.ts:539`), including requests with IDs. A peer waiting for a client response in the probe received none and timed out. Implement bounded client-request dispatch and explicit errors for unsupported methods while keeping notifications non-correlated. This confirms a protocol gap; it does not prove a particular installed server currently triggers it.

07-F10 — MEDIUM — Rust strips `crate::` and tries the caller’s directory before crate root (`import-resolution.ts:275,281,289`). With both root and nested `config.rs`, the explicit crate import incorrectly selected the nested file. Resolve against the owning crate first, then test `self`, `super`, local modules and multiple crates. This is a deterministic heuristic graph error, independently of missing compiler integration.

07-F11 — MEDIUM — Go’s suffix search scans every indexed file (`import-resolution.ts:359`) and accepts a lone matching directory member (`:370`). A fixture with only `pkg/config/main.ts` resolved a Go package import to that TypeScript file. Restrict candidates to the owning Go package and model package membership explicitly. Cross-language references require bridge evidence; sharing a directory suffix is insufficient.

Several strengths should survive the fixes. The registry distinguishes display metadata from launch specifications, rejects duplicate detection signals and ships self-contained guidance rather than reading imaginary idiom files from user projects. The manifest is cloned, versioned and golden-tested. Parser caching retains loaded grammar through optional query failure, reducing repeated WASM loading; AST symbols and same-tree calls share a parse. GDScript uses an immutable source, declared ABI/build provenance and checksum, with bounded streamed downloads and atomic repair. SCIP uses safe relative paths, local-symbol filtering and pure graph merge with accelerator invalidation. Configured validation genuinely executes hooks and rejects stale worktree evidence; no-hooks paths already report reduced assurance. These are working components, not scaffolds to replace.

Security assessment found containment before LSP document-byte reads, safe SCIP paths, fixed argv diagnostics and validated build tokens; it found no demonstrated injection or credential leak. These cooperative checks do not establish an OS sandbox for language-server processes. Correctness and API assessment exposed identity, root, document-ID, version and coverage-contract problems. State/error assessment exposed orphan processes and silent dirty/failed observations. Performance assessment found concrete limits and asynchronous shared discovery caches, but synchronous Cargo/Go owning-target probes can still block the live tool path up to their per-process timeout; no latency benchmark was run. Dependency assessment found declared pinned parser/grammar packages and immutable repair provenance, alongside missing query publication. Test assessment found fixture breadth that does not exercise important component interactions, and a packaged-query script that merely warns about missing expected tokens. Green argv mocks and skip-gated real-server tests are insufficient language certification.

The ready queue should stay short. First, repair package/executable asset authority and run isolated npm/archive semantic probes for every grammar. Include query members/checksums in SDK, both release lanes and wrapper management; preserve public directory override compatibility. In parallel, repair family normalization and Rust/Go import ownership, with real graph fixtures for positive same-language edges and forbidden foreign matches. Also separate SCIP opaque identity from display labels and coordinate durable refresh/snapshot assurance with pair08. These three packages have small existing-source scopes and need no implementation-language migration.

Next, make the multiplexer the document/version and process-lifetime authority. A query followed by an edit must produce fresh bytes under strictly increasing versions; skipped or failed dirty documents must become explicitly unavailable or reopen. Exercise more than64 documents,33-file edits, oversized changes, deletion, malformed framing and disposal during restart. Only then expand protocol interoperability: explicit root-found state, per-extension document identifiers, callback replies, negotiated encodings, server capabilities and root-contextual workspace-symbol results. Run actual clangd plus TypeScript/Python/Rust fixture cells when installed and record unavailable cells without grading skips as success.

Diagnostic work must return command, owning root/environment, exit/cancellation state and coverage before labeling a delta successful. Route nested toolchains to their own roots and expose command/file caps. Keep configured-hook opt-in behavior and no-hooks reduced assurance. Genuine before/after errors, shifted pre-existing errors, missing executables, timeouts and partial output require separate acceptance states. Command candidates must never stand in for execution evidence, and tolerant matching’s residual ambiguity should be explicit rather than described as exact identity.
