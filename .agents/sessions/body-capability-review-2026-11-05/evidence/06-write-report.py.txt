The fixture paused B after its stale decision and A before staging: both public conditional commits against the same original hash returned `applied=true`; A overwrote B's successful result. The probe widened existing awaits with internal DI and did not measure spontaneous race frequency. Repair needs generation-safe takeover serialized with acquisition. Acceptance: competing breakers must preserve a fresh live lock and permit exactly one commit from a shared preimage.

**06-F2 · HIGH — semantic edits adopt a later snapshot.** `language-intelligence.ts:350` reads and splices text, but `semantic-edit-apply.ts:136` forwards only path/new content. `change-file.ts:998` then snapshots current bytes and CAS-protects those newer bytes while committing content derived from the earlier read. A fixture external append disappeared, with `applied=true`. The multiplexer also discards document versions (`lsp-multiplexer.ts:1057,1318`): a framed peer's WorkspaceEdit version 999 applied against didOpen version 1. Preserve the exact source hash and document version across normalization, splice and apply. Acceptance: an intervening append, BOM/EOL-only change or mismatched version must reject without writes.

**06-F3 · HIGH — rollback conflict becomes false applied evidence.** The coordinator records an in-progress action before calling its adapter (`change-file.ts:687`), which is necessary for uncertain partial effects. However, `common/src/tools/results/filesystem.ts:1130` maps every `rollback_failed` to `applied`, and `:1105` treats it as confirmed. In the probe both forward CAS and rollback returned false; the surviving bytes belonged to an external writer, yet the action was confirmed applied. `sdk/src/run.ts:3184` consumes these actions for journal, LSP and observers. Keep forward evidence separate from attempted rollback and expose uncertain observations without promoting them. Acceptance: rejected forward/rollback calls produce zero confirmed actions and preserve foreign bytes.

**06-F4 · HIGH — startup recovery overwrites unowned divergence.** Intent entries contain preimages but no planned after-state (`transaction-intent-log.ts:161`). Recovery interprets any difference from old text as transaction divergence, restores mixed-state paths (`:1249`) and uses unconditional `writeFile`/`unlink` (`:1367`). A fixture's external work was overwritten by the preimage and recovery reported success. Read failure can fall back to unconditional restoration as well. Persist expected after-hashes and action evidence; use conditional recovery only for proven transaction-owned states. Acceptance: faulted group plus external edits must preserve those edits and remain unresolved when ownership is unknown. The probe exercised persisted interrupted state, without killing an OS process.

**06-F5 · HIGH — failed rollback is terminal.** After a restoration throws, `transaction-intent-log.ts:1263` still writes `tx_abort`; later scans consider only last-event `tx_begin` (`:1161`). Injected write failure left divergent bytes, but the next scan returned no pending transactions. SDK startup marks its once-per-process key before recovery and ignores its structured failure (`sdk/src/run.ts:965`). Persist a nonterminal recovery-required state, retain unfinished paths and mark successful startup recovery only after a conclusive result. Acceptance: fail once, recover filesystem availability, then retry successfully; restart must retain the unresolved intent and callers must see its state.

**06-F6 · HIGH — a partial WorkspaceEdit breaks interfaces.** Failed peer splices are removed while successful files survive (`language-intelligence.ts:418`). The apply core reports the surviving coordinator's success (`semantic-edit-apply.ts:94`). A declaration changed `foo` to `bar` while its failed consumer retained `foo`; output had `applied=true` plus an error. Unsupported resource operations are recorded as skipped but discarded by `lsp-multiplexer.ts:1171,1318`; another fixture omitted a requested file rename and applied text edits without any error. Preserve every operation/refusal and preflight the complete refactor. Acceptance: declaration/consumer/resource changes all complete, or all files remain untouched with a structured refusal. The CLI's partial label cannot restore interface consistency.

**06-F7 · MEDIUM — UTF-8 BOM preimages are not exact.** Default `TextDecoder` strips BOM in both `read-files.ts:297` and `change-file.ts:958`; the broker compares raw bytes. No fixture bytes changed, though rollback-incomplete was reported; false applied evidence is F3. Keep original bytes/BOM metadata authoritative and normalized freshness separate. Acceptance: ordinary read/edit/delete/move and rollback on BOM files preserve intended BOM, mode, untouched EOL and final-newline bytes with exact matching receipts.

**06-F8 · MEDIUM — scoped edits alter unrelated line endings.** `process-edit-transaction.ts:1241` builds range output from the whole LF-normalized snapshot; `:1319` does the same for symbol rewrite. A broker-backed one-line range edit converted all three CRLF terminators to LF. `str_replace` has original-line restoration (`process-str-replace.ts:991`) and its own mixed-EOL test, but other variants bypass it. Share a lossless localized splice/render path. Acceptance: every localized variant preserves byte equality outside its target across CRLF, mixed EOL, BOM, astral text and missing final newline. Only range conversion was executed; symbol conversion is directly inspected code evidence.

**06-F9 · MEDIUM — malformed server positions reach disk.** Normalization checks `typeof number` (`lsp-multiplexer.ts:1095`), and the offset conversion lacks nonnegative/integer checks (`language-intelligence.ts:262`) or ordered range validation. Negative characters on the second line edited the first; reversed ranges duplicated text and fractional offsets were truncated. Default compliant LSP UTF-16 units match JavaScript; this does not prove alternate encoding support. Acceptance: malformed positions refuse without writes, valid astral UTF-16 positions preserve bytes, and other encodings are negotiated/converted or refused explicitly.

**06-F10 · MEDIUM — valid transactions silently lose durable recovery.** Mutation limits allow 16 MiB per file and 64 MiB rollback state (`common/src/actions.ts:17`), while the complete default intent log is capped at 8 MiB (`transaction-intent-log.ts:128`). `change-file.ts:658` proceeds when durable begin fails. Acceptance: capacity/fsync refusal causes zero commits; accepted groups survive a killed/faulted mid-commit run.

**06-F11 · MEDIUM — bounded output hides unbounded line buffering.** `node-filesystem.ts:147,152,162` accumulates and concatenates complete lines before checking the returned-byte budget, including irrelevant lines. A 24 MiB unbroken fixture with a 1 KiB budget returned zero bytes but performed a 24 MiB concat. This instrumented allocation is evidence, not an RSS/throughput benchmark. Count skipped newlines without retaining their text, discard over-budget selected lines and add cancellation support. Acceptance: peak buffering remains within budget plus fixed chunk overhead, metadata stays honest, streams close on abort and incomplete reads mint no authority.

**06-F12 · HIGH — broker recovery escapes canonical containment.** `absoluteFromRelative` checks only lexical paths (`workspace-mutation-broker.ts:918`); recovered delete follows its current parent and unlinks staging (`:689`). Ordinary commits check parent realpath at `:899`.
