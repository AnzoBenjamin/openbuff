## Strengths worth preserving

The approval store holds read/consume under a kind lock, verifies workspace/run/snapshot/action/target/hash, rejects malformed expiry and consumes once (`harness-enforcement.ts:86-123`). Approved terminal reruns keep assistant mode and profile, rechecking cwd rather than bypassing the helper as user mode. Runtime-injected owners override model inputs, and foreign-owner kill is rejected before OS signaling. Background jobs provide real incremental UTF-8 observations, bounded event rings, live UI forwarding, owned cancellation and explicit detach. These are substantive body capabilities, not merely agent instructions.

Output handling is also useful: bounded head/tail capture retains startup and recent context; a disk spool preserves overflow with backpressure and recovery paths. Compiler capture measures bytes and decodes after accumulation. Hooks distinguish no configured checks from skipped checks and propagate cancellation after concurrent settlement. Chrome uses private temporary profiles, prefers private CDP pipes, rolls back failed starts and protects stop-versus-spawn registration. Its Linux no-sandbox fallback is deliberately documented and tested; this audit does not redefine that preference as a defect.

The native slice is real. The fresh binary handshook, forwarded a harmless target and reported explicit degraded status when Landlock was disabled. It does not prove D48 network, Unix-socket or syscall isolation.
